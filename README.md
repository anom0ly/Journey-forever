# Journey Forever

Records your journey through WoW Forever, level 1 to 60, and shows it on a
website after each session: the road you walked replayed on the map, with
levels, quests, deaths, dungeons, loot, gold and screenshots along the way.

- [`addon/`](addon/): the Journey Forever addon (screenshots on dungeon clears,
  epic loot and level ups, plus `/jf note`). It runs alongside Road to Sixty
  and Journey Tracker, which record the path and the stats.
- [`website/`](website/): the site that reads all three addons' saved files.
  See its README to run it locally or deploy it to Cloudflare.
